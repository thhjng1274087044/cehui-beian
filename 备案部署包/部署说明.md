# 自动备案小程序 · 服务器部署说明

把房产测绘「房测报告」信息自动填入浙江省测绘地理信息综合监管服务平台并上传合同附件。
本包为**离线自包含**：台账数据、已上传记录、未上传记录的 PDF/合同缓存已全部打包，服务器上**不依赖**原 `W:/2020备案` 网络盘即可完成剩余备案上传。

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows Server 2016/2019/2022（桌面体验需开启，因要跑 Chrome 图形界面） |
| Python | 3.10 及以上（开发机 3.13.14 验证通过） |
| Google Chrome | 已安装（脚本复用本机 Chrome，不走无头浏览器） |
| 网络 | 能访问 `hyjg.zrzyt.zj.gov.cn`（政府备案网）；能访问外网下载 pip 包 |

> ⚠️ 服务器必须能显示桌面 / 运行图形界面浏览器。Core 版无桌面的话，需另装桌面体验或改用带桌面的系统。

---

## 二、安装步骤

```bat
:: 1) 建虚拟环境（推荐，避免污染系统 Python）
cd <部署包根目录>
python -m venv venv
venv\Scripts\activate

:: 2) 装依赖
pip install -r requirements.txt
:: 注意：脚本用本机已装 Chrome 的 CDP 模式，【不需要】执行 playwright install
```

若服务器不能上外网装 pip 包，可在能上网的机器上用同一 Python 版本
`pip download -r requirements.txt -d wheels` 下载离线包，再拷到服务器
`pip install --no-index --find-links=wheels -r requirements.txt`。

## 三、配置（通常只需确认 2 项）

编辑根目录 `config.json`：

- `chrome_path`：改成服务器上 Chrome 实际安装路径（默认 `C:/Program Files/Google/Chrome/Application/chrome.exe`）。
- `cdp_url`：Chrome 调试端口，默认 `http://localhost:9333`，与 `start_chrome.bat` 里的 `PORT` 保持一致即可，一般不用改。

其余路径（`ledger`/`cache`/`browser_profile` 等）都相对于部署包根目录，**保持默认即可**。
`legacy_cache_root` 用于把台账里写死的旧路径翻译成新缓存位置，一般不用动。

## 四、运行流程

### 第 1 步：启动 Chrome 并手动登录
```bat
start_chrome.bat
```
浏览器会打开政府备案网。**必须人工登录**（有图形验证码，脚本无法自动填）。
登录态约 **4 小时**失效——失效后回到该浏览器窗口重新登录即可，脚本会自动续跑。

### 第 2 步：运行上传（断点续跑）
```bat
:: 上传台账内全部待备案记录（已上传过的会自动跳过）
python beian_fill.py --all

:: 只想先试几条：
python beian_fill.py --all --limit=3

:: 只跑某个月：
python beian_fill.py --all --month=202401
```
脚本行为：
- 以 `beian_upload_log.json` 去重，**已上传（done）的绝不重跑**。
- 无合同的记录按规则**自动跳过**（不传、不删、不标记失败），将来补了合同再跑 `--all` 会自动纳入。
- 登录掉线 → 优雅暂停，等你在浏览器重新登录后**自动续跑**（无需从头）。
- 进度指针在 `beian_progress.json`。

### （可选）第 3 步：若服务器能挂上 `W:/2020备案` 重新提取
```bat
python beian_extract_worker.py --root "W:/2020备案"
```
离线包已含完整缓存，**一般不用跑这步**；仅当要补录新盘上的报告时才需要。

## 五、数据文件说明（包内）

| 文件 | 作用 |
|---|---|
| `beian_records.json` | 台账主数据：每条报告的提取字段 + 合同路径 + 状态 |
| `beian_upload_log.json` | 上传去重日志（729 条已上传记录，已核实） |
| `beian_records_gold.json` | 黄金样本（校验用） |

> 当前台账 2561 条：已上传 729 条；待传 1832 条中 224 条无合同将跳过，约 **1608 条可离线上传**，其合同图片在缓存中 100% 齐全。

## 六、已知限制 / 注意事项

1. **登录验证码**：政府网登录有图形验证码，必须人工登录一次（约 4h 一次）。无法全自动。
2. **上传节奏**：脚本模拟人工操作（随机延时 + 模拟鼠标），单条约 100 秒，1608 条约需数十小时，**分多天、断点续跑**即可。
3. **上传后清理**：每条上传成功后，脚本会删除该条在 `.pdf_cache` 里的本地副本，只留台账标记，避免磁盘爆满。
4. **打印机扫描问题**：与本项目无关，见 `交接文档.md`（公司打印机 bizhub C368 的 WSD 扫描协议被关，需管理员密码开启）。

## 八、传输与解压提示

- 整个包约 **2.8GB**（其中 `.pdf_cache` 2.7GB 是已压缩的 PDF，体积基本压不动）。
- 发包形式有两种，任选其一：
  1. **直接复制文件夹** `备案部署包/`：包本身已自包含，**无需解压即可在服务器上直接运行**，最省事。
  2. **用 `备案部署包.zip` 单文件传输**：采用 ZIP64 格式。
- ⚠️ 超大 ZIP64 文件用 Windows 资源管理器的「全部解压缩」可能报错。若遇到，请用 **7-Zip**（https://7-zip.org，免费）或 WinRAR 解压，或直接复制上面那个文件夹即可。
