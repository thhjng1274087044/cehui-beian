## 打印机扫描问题（2026-08-20 记录，未解决）

### 现象
- 柯尼卡美能达 bizhub C368（IP `192.168.0.227`，设备名 KM_C368，序列号 A7PU087004988）
- **能打印**（走 LPR 515 / RAW 9100 直连，正常），**扫描不过来**
- 影响范围：192.168.0.x 网段内的其他电脑（同网段有线机），非跨网段问题

### 已诊断结论
| 检查项 | 结果 |
|---|---|
| 端口 515 / 9100（打印） | ✅ OPEN |
| 端口 80（Web 管理） | ✅ OPEN |
| 端口 3702 / 5357 / 5358（WSD 扫描协议） | ❌ 全部拒绝 |
| Windows 扫描仪设备列表 | 空（`Get-PnpDevice -Class Image` 无设备） |
| 网络发现服务 fdPHost/FDResPub | Stopped（次要因素，同网段时可自动发现） |
| 防火墙 WSD 规则 | 全部放行（非防火墙问题） |
| Web 后台登录（/wcd/login.xml → login.cgi） | 试 8 个默认密码全失败："Authentication failed" |

### 根因
1. **打印机 WSD 协议未启用**——扫描必须靠 WSD 被发现，WSD 关着 → 所有电脑都找不到扫描功能；打印走传统 515/9100 不受影响
2. **管理员密码被装机供应商改过**——想远程/面板开启 WSD 都被密码挡住，无法自助解决

### 当前卡点
- 缺 **bizhub C368 管理员密码**（或 CE/服务工程师密码），无法进网络设置开 WSD

### 下一步（按推荐顺序）
1. **找供应商要管理员密码**（装机报告上一般有，最快）
2. 面板 `Utility/Counter → 管理员设置` 用 CE 密码重置管理员密码
3. 不依赖 WSD 的替代：**扫描到 SMB 共享文件夹**（面板协议列表显示"SMB发送 开启"，但注册目标同样要管理员密码，卡同一密码）
4. 重装柯尼卡官方驱动（含 TWAIN/WIA 扫描组件 + Scan-to-PC 工具，走私有协议，不依赖 WSD）

### 其他待办事项（顺带发现）
- ⚠️ **青色（C）碳粉 0% 已空**，需更换，否则彩色打印缺青色
