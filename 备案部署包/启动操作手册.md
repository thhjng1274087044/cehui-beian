`start_chrome.bat` **不再写死路径**，会自动按顺序找：

1. `%ProgramFiles%\Google\Chrome\Application\chrome.exe` ← 本机走这条
2. `%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe`
3. `%LocalAppData%\Google\Chrome\Application\chrome.exe`

## 第 1 步 · 启动浏览器

**双击 `E:\网站备案\备案部署包\start_chrome.bat`**。会弹出一个独立 profile 的 Chrome（登录态存在 `browser_profile_beian`，下次还认）。

- 如果窗口没出现 → 翻任务栏（可能被最小化了）；也可以看 bat 窗口的提示。
- 如果提示 `[!] 端口 9333 已在监听` → Chrome 已经在跑了，不要重复启动。

## 第 2 步 · 人工登录（必须手动）

浏览器会打开政府备案网，**人工输账号 + 密码 + 图形验证码**登录。
- 账号：`XDL13858623456`（密码按你手上存的）
- 图形验证码脚本无法自动识别，**这一步全自动不了**
- 登录态约 **4 小时**失效

**验证 checkpoint（两种任选）**：
- 登录后直接回到 `start_chrome.bat` 的窗口**按任意键** → 会自动跑一次自检
- 或者双击 `检查登录状态.bat`（会自动挑一个装了 playwright 的 python）

看到 `"has_password_input": false` → **已登录，可以开跑**。
看到 `true` → 还没登录 / 登录态过期，回 Chrome 重新登录。

> 自检前置条件：9333 端口得有监听。没监听它会直接提示你先跑 `start_chrome.bat`。

## 第 3 步 · 跑自动备案（断点续跑）

```bat
cd /d E:\网站备案\备案部署包

:: 先试 3 条，确认流程通
python beian_fill.py --all --limit=3

:: 确认没问题，正式跑全部（按月顺序）
python beian_fill.py --all

:: 只想跑某个月 / 连续区间
python beian_fill.py --all --month=202401
python beian_fill.py --all --month=202401-202406

:: 只打印不操作浏览器（先看会跑哪些）
python beian_fill.py --dry-run
```

**验证 checkpoint**：启动后日志里应出现

```

共 N 条可填报（跳过 提取未通过/已上传/无合同 共 X 条，其中无合同 Y 条）；已上传累计 729 条
```

## 跑到一半的三种情况

| 情况 | 会发生什么 | 你要做什么 |
|---|---|---|
| **Ctrl+C 中断** | 进度自动存 `beian_progress.json` | 重新跑 `--all` 即从断点续 |
| **登录掉线** | 脚本**原地暂停**，每 30s 探一次 | 回 Chrome 窗口重新登录 → **自动续跑，不用重启命令** |
| **某条失败** | 该条不标记，其余继续 | 跑完后重跑 `--all` 会自动重试 |

**其他自动行为：**
- 已上传的**绝不重跑**（`beian_upload_log.json` 去重）
- **无合同的自动跳过**（不传、不删、不标失败），以后补了合同再跑 `--all` 会自动纳入
- 每条上传成功后**删掉该条本地 PDF/合同副本**（防爆盘）
- 单条约 100 秒，1600 条要几十小时 → **分多天跑**即可

## 首次在新机器上装环境（只有换机器才需要）

```bat
cd /d E:\网站备案\备案部署包
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
:: 用本机 Chrome 的 CDP 模式，【不需要】playwright install
```

依赖：`playwright` `PyMuPDF` `openpyxl` `pdfplumber`

改配置只改 `config.json`：`chrome_path`（Chrome 实际路径）+ `cdp_url`（默认 `http://localhost:9333`）。
